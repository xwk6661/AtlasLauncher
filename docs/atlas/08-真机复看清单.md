---

## 0. 准备

1. 用**便携版**：`E:\Program File\AtlasLaucher\atlas.exe`（数据就在旁边）。
   不要用 `build\win-local\Debug\atlas.exe` —— 它是界面调试版，会和便携版抢同一份数据。
2. **不要同时开两个启动器**。
3. 如果装了 ToDesk / 向日葵，先**断开**（不是关窗口）。远控的虚拟输入会让游戏视角发疯，
   排查时会被误当成启动器的问题。
4. 先复制一份 `maps\` 目录到别处（约 4.7 GB，可只复制要动的那几个 zip）。
   下面的 A/B 两项会真的删文件。

---

## A. 删除拒绝：别人正在用的包不能删（P0 #9 前半）

**要防的事**：删掉一个实例还在用的源包 → 那个实例以后「重装」找不到源，等于半废。

1. 打开「本地库」页（侧栏，在「CTM 地图」下面）。
2. 找一个**已安装**的包（行上有已安装标识 / tooltip 里写着实例名）。
3. 右键 → **「删除全部版本…」**。
4. 期望：弹窗**拒绝**，并列出"还有 N 个实例在用：实例名…"；`maps\` 里的 zip 还在。
5. 再找一个**从没装过**的包（列表里没有已安装标识）：
   右键 → 删除 → 应在确认后删掉；列表里消失，`maps\` 里对应 zip 也没了。

**通过**：拒绝时列出实例名且文件仍在；无实例的包能被正常删除。
**失败长什么样**：拒绝的弹窗没有说明；或已安装的包真的被删（`maps\` 文件数变少）。

---

## B. 规范命名之后还能重装（P0 #9 后半）

**要防的事**：批量改名把文件名改了，实例的 `map.json` / 库索引还指着旧名 → 重装找不到源包。

1. 本地库页 → 右键 → **「规范命名…」**，等状态栏给出结果（应说明改了几个）。
2. 随便挑一个**刚被改过名**的实例（或本来就叫 `[1.16.5] …` 的），打开实例窗口 → 「地图」页。
3. 点「重装」（会问是否备份旧存档，默认勾选 → 选「是」）。
4. 期望：能定位到源包 → 解压 → 完成后启动能进图。

**通过**：重装走完且能进图；实例目录里的 `map.json` 仍指向存在的库文件。
**失败长什么样**：重装对话框提示找不到源包；日志出现
`Failed to open archive file <路径>`（这个路径应该指向 `maps\` 里的库副本）。

---

## C. 导入对话框的九项设置真的写进去了（P0 #5）

**要防的事**：勾了"中文 / 全屏 / 关云"，进游戏发现没生效 —— 写错键名不会坏档，但玩家会以为功能坏了。

准备：一张 **1.16.5** 的图、一张 **1.8.9** 的图（版本不同，键名写法不同）。

1. 拖入 / 「导入地图…」→ 在导入对话框里把九项都改成**非默认**：
   语言=简体中文、全屏=开、云=关、自动跳远=开、视角键=交换、视野=90、视角摇晃=关、亮度=暗。
2. 导入完成后，用记事本打开 `instances\<实例名>\.minecraft\options.txt`，逐行对：
   - `lang:zh_cn`
   - `fullscreen:true`
   - 云：1.16.5 是 `renderClouds:"false"`（**带引号**）；1.8.9 是 `renderClouds:false`（不带）
   - 键位：1.8.9 起是 `key_key.sprint`/`key_key.sneak` 这一代写法；更老的是 `key.keyboard.*`
3. 两张图各启动一次，看日志有没有 `Skipping bad option: <键名>`（有就是写错了键）。

**通过**：九项都在、写法与版本对得上、日志没有 `Skipping bad option`。
**失败长什么样**：缺项；`lang` 写成 `zh_CN`；1.8.9 出现 `key.keyboard.*`；
或进游戏后设置被重置回默认（说明文件格式让游戏读挂了）。

---

## D. 1.20+ 点卡片进图（P0 #8，唯一还缺的那一半）

**要防的事**：这是产品的主路径，也是唯一没有在**便携版**上跑过的轨道（11-20 跑的是 1.9.4 的 Agent 轨道）。

1. 点一张 **1.20 以上**的地图卡片 → 启动。
2. 期望：不出现「实验性设置」确认页 → 直接落在出生点。
3. 按 Esc → 「保存并退出」→ 游戏窗口**自己关掉**（回到启动器）。

**通过**：三条都在。日志（`logs\Atlas-0.log`）应能看到：

```
Map launch plan: … track= 0 (quickplay)      ← 走的是 quickPlay 轨道
introskip … 已跳过确认页
Map quit watcher: …                          ← 未出现也没关系，说明游戏自己退了
```

**失败长什么样**：停在主菜单（`track= 2` 或根本没有 `Map launch plan:` 行）；
退出后窗口不关（`Map quit watcher:` 之后 10 秒仍在）—— 这两种都请附日志。

---

## 5. 做完发回什么

只发这三样就够定位问题，不用描述：

1. `logs\Atlas-0.log`（整个文件，或者从最后一次启动往前 200 行）；
2. 出问题那个实例目录里的 `map.json` 与 `agent.log`（没有 `agent.log` 就只发 `map.json`）；
3. 一行结论：哪一步、期望什么、实际什么（例如「A 第 4 步：期望拒绝，实际删掉了」）。

> 「导出诊断包」按钮还没做（[07](07-发布清单.md) 阻断项 #3）。做完之后这三样会被一键打成一个 zip。
