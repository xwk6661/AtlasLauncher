## 6. 接手第一小时

**真机一律用便携版**：`E:/Program File/AtlasLaucher/atlas.exe`（数据就在旁边）。`build\run-atlas-debug.cmd`
起的 Debug 只做界面——它靠 `--dir` 复用同一份数据，别和便携版同时开。

1. **确认基线**：跑 `ctest -C Debug`，应 33/33（本机 20–33 秒，看负载；近期实测 20.55 / 22.95 / 25.29 / 32.01 秒）；逐套件 448 项，数字对不上先看符号链接权限
   （[02 §5](02-构建与运行.md)）。
2. **核对版本**：`git log --oneline -5`、`git status`；工作区应干净（构建产物在 `build/`，已被忽略）。
   仓库已是独立仓库（`gh repo view --json isFork` 应为 `false`），**tag 应为 0 个** ——
   如果看到一堆 `1.0.0`…`12.0.0`，说明是从上游 fork 的老克隆。
   **便携根里装的是 11-23 的包，代码已前进若干提交**：动手前先 `tools/deploy-local.ps1` 重新上机。
3. **走主流程**：拖一张 1.20+ 地图 → 选「作为地图导入」→ 确认 → 选中实例（右侧出现地图卡片）→
   启动 → 不应弹「实验性设置」→ 落在出生点 → 退出存档 → 游戏自己关。
   **如果鼠标/视角发疯，先断开远程控制软件**（[03 §4](03-决策与坑.md)）。
4. **看日志**：地图只认四个前缀 —— `Map launch plan:`（轨道与原因）、`Map quit watcher:`、
   `Map window focus:`、`introskip`（`已跳过确认页`）。下载看 `Splitting … into N ranges`、
   `Request failed … retrying from`、`Network stalled`、`No response in 20 seconds`、
   `Transfer idle for 20 seconds`、`Download is crawling at`、`Resuming … from byte N`。
5. **看大厅**：添加实例 → CTM 地图 → 等封面（首次约 12 秒）→ 搜索/筛选/详情/评论。
6. 然后按 §4 的 P0 → P1 推进。
7. **改完代码怎么上机**：`powershell -File tools\deploy-local.ps1` —— 构建 → 打包 → 覆盖便携根一条命令走完；
   先 `-DryRun` 看体检（启动器在跑会直接拒绝，不会把 exe 复制到一半）。
