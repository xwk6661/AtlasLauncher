Atlas —— 以地图为中心的 Minecraft 启动器
========================================

点一张地图，直接落进它的世界。基于 Prism Launcher（GPL-3.0）。


一、这是什么
------------

普通启动器是「先选版本 → 等主菜单 → 挑存档」，Atlas 把顺序反过来：
导入一个地图压缩包，它就替你建好一个隔离的实例，之后点卡片就能直接进图。

    · 一张地图 = 一个实例：只解这一个存档，材质包就地装上，互不影响
    · 版本由存档推断：读 level.dat 与文本旁证，给出结论、置信度与证据；
      判不出来就拒绝导入，绝不猜（用高版本打开旧存档会不可逆地升级存档）
    · 点开就进图：1.20 及以上用官方的 --quickPlaySingleplayer；
      1.19.4 及以下用随包的 Java Agent
    · 退出即关：确认存档落盘后才结束游戏进程，不丢进度
    · Java 按版本自动选：1.16.5 及更早用 8、1.17 用 16、1.18–1.20.4 用 17、
      1.20.5 及以上用 21


二、第一次使用
--------------

1. 解压到一个**你有写权限**的目录（例如 D:\Games\Atlas）。
   不要放在 C:\Program Files —— 这是便携版，数据就写在 exe 旁边。
2. 双击 atlas.exe。第一次启动会自动拉取版本清单与中文语言包（需要联网）。
3. 右上角头像 → 添加账号 → 用微软账号登录（需要正版 Minecraft）。
4. 左侧「添加实例」→「导入」→ 选一个地图 zip / rar / 7z，或直接把压缩包拖进窗口。
   导入前会让你确认版本、语言与九项游戏设置。
5. 选中实例 → 右侧出现地图卡片 → 点「启动」。
   第一次启动要下载这个版本的核心、依赖与素材，视网速可能要几分钟。


三、数据都在哪
--------------

全部在 atlas.exe 所在的目录里（便携模式）：

    instances\        每个地图实例（存档、模组、设置）
    maps\             地图库的压缩包与索引
    assets\ libraries\ java\     跨实例共享的资源（可整体搬到别的盘）
    accounts.json     账号
    logs\             启动器日志

备份 = 复制整个目录。换机器 = 把目录搬到新机器再运行。
「设置 → 资源」里可以把 assets / libraries / java 迁到别的盘，不会重新下载。


四、已知限制（首发版本）
------------------------

· 只有 Windows x64 的便携包，没有安装器。
· 界面以中文为主；未翻译的条目会回落到英文。
· 1.17 / 1.18 无法自动进图（游戏没有对应的入口类），会停在主菜单。
· 26.x（新版本号写法）会被拒绝导入：官方不再提供映射表，无法生成符号表。
· RAR5 的分卷包、加密头未经验证；遇到失败请先转成 zip。
· 大厅（发现地图）依赖第三方站点 CTM Maps，站点不可达时会退化成离线模式；
  下载地图一律交给系统浏览器，启动器内不下载地图。

完整的功能状态与每项验证到哪一档，见 GitHub 仓库的 docs/atlas/。


五、出问题了怎么办
------------------

先看 logs\Atlas-0.log，搜索这几个关键字，通常就能定位：

    Map launch plan:     这次走的是哪条轨道、为什么
    Map quit watcher:    退出看门狗有没有挂上、有没有关窗
    Map java:            选了哪个 Java、为什么
    introskip            这个版本有没有跳过「实验性设置」确认页

提 issue 时请附上：Atlas 版本（关于页可复制）、日志尾部、以及这张图的
instances\<实例名>\map.json 与 agent.log。
