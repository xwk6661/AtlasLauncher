# 许可文本清单

本目录是**随安装包一起分发**的完整许可文本，供离线阅读与合规审查。
`THIRD-PARTY-NOTICES.md` 里的每个组件都在这里指到具体文件。

| 文件 | 覆盖的组件 |
| --- | --- |
| `LICENSE`（仓库根，随包名为 `LICENSE.txt`） | Atlas 自身代码：GPL-3.0-only 全文 |
| `GPL-3.0-only.txt` | 同上（单独的副本，方便按需引用）；Agent jar；`pe_*` 图标集（Simple） |
| `LGPL-3.0-only.txt` | Qt 6、KDE Breeze 图标 |
| `LGPL-2.1-only.txt` | libqrencode |
| `GPL-2.0-only.txt` | lzo（libarchive 的可选后端，实际按 "or later" 使用） |
| `Apache-2.0.txt` | MultiMC 的 Legacy 图标；Google Material Icons |
| `MIT.txt` | tomlplusplus、qdcss、rainbow、murmur2、LocalPeer、libnbt++ |
| `BSD-2-Clause.txt` | libarchive、cmark、lz4 |
| `BSD-3-Clause.txt` | ASM 9.7.1（随 Agent jar）、zstd（BSD 分支） |
| `0BSD.txt` | liblzma（XZ Utils） |
| `Zlib.txt` | zlib |
| `OFL-1.1.txt` | Material Design Icons（Austin Andrews，`flat` 图标的来源之一） |
| `packages/libarchive.txt` 等 | 各依赖自带的**版权声明 + 许可原文**（vcpkg 打包时附带的 `copyright`），保留原始版权人 |
| `packages/qt.txt` | Qt 的版权与 LGPL-3.0 合规说明（动态链接、可替换 DLL） |
| `packages/asm.txt` | ASM 的 INRIA 版权声明 + BSD-3 条款 |
| `packages/icon-themes.txt` | 四套界面图标（Breeze / Material / Legacy / Simple）的署名与许可对照 |

> 这些文本按各自许可证原文收录，**不翻译、不改写**；中文说明只出现在 `THIRD-PARTY-NOTICES.md`
> 与本文件里，不构成对许可条款的解释。
