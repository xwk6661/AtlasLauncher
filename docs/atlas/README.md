# Atlas · 文档索引

**Atlas** 是一个以地图为中心的 Minecraft 启动器（0.1.0，C++/Qt 6.8，基于 Prism Launcher）：
把 AIO 版（`Minecraft-AIO`，独立仓库）的「点地图进图」搬到原生 Qt 上 ——
**点一张地图卡片，直接落进它的世界；版本由程序从存档推断。**

> 状态、进度与所有具体数字只看 [04](04-进度与待办.md)；每项功能验到哪一档只看 [05](05-验证记录.md)；
> 动手前必须先读的规则在 [00](00-工程约定.md)。本页只做导航，不维护任何会变的数字。

## 30 秒速览

**已经能做的**

- 导入地图（zip / rar / 7z）→ 免解压嗅探 → 三级版本判定（带置信度与证据）→ 建**物理隔离**的实例；
- 点开就进图：≥1.20 走 `--quickPlaySingleplayer` + `introskip`；≤1.19.4 走随包 Java Agent（60 张符号表）；
- 退出即关：Agent 确认落盘后自退；≥1.20 由启动器读两句原版日志后关窗；
- Java 按版本自动选，只改「没手选过」的实例；
- 下载自己找路：重试 / 换源 / 两道看门狗 / 连接池 / 续传 / 分片；
- 大厅整库本地化（2287 张，离线可搜可看），本地库按**系列 → 地图**两层；
- 模组预设按实例版本现查 Modrinth / CurseForge 并补依赖；
- 导入时可选九项游戏设置；资源库可整体搬到别的盘。

**明确不做的**

- 启动器内下载（Cloudflare 只认可见浏览器）；
- 自研 ECH / QUIC（Qt 在 Windows 走 Schannel，直接借本机 Chromium）；
- 「一个高版本核心通吃」（1.13 / 1.20.5 两次语义断裂，DFU 不翻译命令方块）；
- 启动器内的地图机器翻译（2026-11-15 整体移除）。

**已知不支持**

| 情况 | 结果 |
| --- | --- |
| 1.17 / 1.18 | 没有 `WorldOpenFlows`，只能停在主菜单 |
| 26.x 新布局且无版本号 | 拒绝导入（判成低版本 = 不可逆降级） |
| 无符号表的版本（1.0–1.5.2、1.14–1.14.3…） | 普通启动，停主菜单 |
| RAR5 分卷 / 加密头 | 未验证，建议转 zip |

## 术语

| 词 | 含义 |
| --- | --- |
| **地图实例** | 一张地图一个 Prism 实例，靠 `map.json` 判定；`saves/` 里只有它自己的存档 |
| **`map.json`** | 自动产生的元数据：来源包、版本证据、世界列表、统计、语言变体。重装会覆盖 |
| **`notes.json`** | 玩家自己的数据：中文名 / 评分 / 笔记。**任何自动流程都不许碰** |
| **`MapWorld`** | 世界目录的固定英文名（quickPlay 与 Agent 都吃字符串，中文路径有历史坑） |
| **资源库** | `assets` / `libraries` / `java` 三份跨实例共享资源；可整体迁移，改完立即生效 |
| **轨道 A / B** | A = ≥1.20 的 `--quickPlaySingleplayer`；B = ≤1.19.4 的 `-javaagent` 注入 |
| **Agent** | `quickboot.jar`，按符号表拼参数，进图后写 `agent.log` 供宿主判定退出是否安全 |
| **introskip** | `introskip.jar`，把 `WorldOpenFlows.askForBackup` 改成直接 `loadLevel`，跳过「实验性设置」页 |
| **浏览器通道** | 借本机 Edge/Chrome 无头模式取数据/取封面。目标站被封的是 SNI，Qt 没有 ECH |
| **大厅本地库** | `<数据目录>/maps/hall-cache.json`，整库拉全量，之后全部本地计算 |
| **便携模式** | exe 旁放 `portable.txt`，数据根 = exe 目录（真实根：`E:/Program File/AtlasLaucher`，拼写就是 `Laucher`） |
| **系列标签** | 实例名前缀 `[US1]` / `[RC3]`；网格里显示成名字下方药丸，文本由 `SeriesNames` 翻译 |
| **验证档位** | L0 编译 / L1 单测 / L2 真实产物 / L3 真机（定义只在 [05 §1](05-验证记录.md)） |

## 维护约定

**写文档前读 [00 §1–§2](00-工程约定.md)**，三条最关键：

1. **一份信息只有一个权威位**：数字在 04、证据在 05、决策在 03、结构在 01、改动在 06；
2. **编号即接口**：`06 §N` 被代码引用、`01 §7.x` 被文档互引，重组时保留编号，废弃小节留指针；
3. **改完跑** `python tools/docs_check.py`，**0 问题才算改完**。

新增界面文案改了 `tr()` 源串 → 必须同步 `launcher/resources/i18n/atlas_en.json`
（`python tools/i18n_extract.py --check`），见 [00 §4](00-工程约定.md)。
