## 5. 发布动作（打 tag 那天）

**打 tag 之前的四项检查**（不满足就别发）：

1. §2 剩下的两条阻断项清零（诊断包、更新通道）；
2. 包内 **43 条目**，且确有 `LICENSE-branding.txt`（[04 P2 #35](04-进度与待办.md)）；
3. 远端 tag 数为 **0**，首发从 `v0.1.0` 起（继承的 59 个上游 tag 已于 11-25 移除；本地只留回滚点 `backup/pre-release-2026-11-23`）；
4. `main` 与 `origin/main` 一致、工作区干净。

```powershell
# 0) 先打 tag 再 configure —— BuildConfig.cpp 是配置期生成的，只 `--build` 不会重读 tag，
#    包里的版本串会沿用上一次配置看到的 tag（11-25 踩过：打了 tag 也显示成开发版）
git tag -a v0.1.0 -m "Atlas 0.1.0"
& .\build\run-configure.ps1 -Action configure

# 1) 产物
cmake --build --preset win-local-release
#    → dist\Atlas-0.1.0-win64-release.zip
& .\tools\package-windows.ps1 -Config Release

# 2) 冒烟：直接跑包里的 exe（不要跑 build 里的）：版本 0.1.0、界面中文、能起窗口、
#    菜单里没有「帮助 / Matrix / Discord / Reddit」，关于页链接指向本仓库

# 3) 校验和
Get-FileHash dist\Atlas-0.1.0-win64-release.zip -Algorithm SHA256

# 4) 推 tag 并建 Release（tag 已在第 0 步打；目前已在 main 上，禁强推）
git push origin v0.1.0
gh release create v0.1.0 dist/Atlas-0.1.0-win64-release.zip --title "Atlas 0.1.0" --notes-file release-notes.md
```

- tag：`v0.1.0`（与 `Launcher_VERSION_NAME` 一致；updater 若启用会按这个比对）。
  **打了 tag 标题才是 `Atlas 0.1.0`**；不打就是 `Atlas 0.1.0-<分支名>`，一眼能看出不是发布版
  （`buildconfig/BuildConfig.cpp.in` 的两处修正见 [06 §131](06-变更记录.md) 六）。
  本机上游 tag 已清空，只剩回滚点 `backup/pre-release-2026-11-23`。
- Release 附件：`Atlas-0.1.0-win64-release.zip` + 一行 SHA-256
- Release 说明至少写：**这是 0.1.0，未签名（SmartScreen 会提示未知发布者）**、便携版数据在 exe 旁、
  1.17/1.18 不能自动进图、问题反馈附日志（诊断包做完后改成一个 zip）
- GitHub 会把最新的非 prerelease 标成 Latest；**只保留一个 Latest**，旧包留链接但不要抢 Latest

## 6. 宣发口径（B 站等）

只讲三件别人做不到/没做的事，不要罗列功能：

1. **点一张地图，直接落进它的世界**（不是"又一个启动器"）；
2. **版本由程序从存档推断，判不出就拒绝导入**——顺手解释为什么不能用一个高版本核心通吃；
3. **≤1.19.4 也能直连**（Java Agent + 60 张符号表），这是绝大多数启动器不做的一段。

同时说清边界：只有 Windows 便携版、非官方、不含游戏文件、需要正版账号、
大厅数据来自 CTMMaps。

## 7. 与上游的"隔离"清单

目标：**基于上游、但作为独立项目存在**。界面上不出现任何上游站点，启动时不为品牌目的访问上游，
技术上必须依赖的部分保持并写清原因。

### 7.1 保留（技术必需，不是耦合）

| 项 | 位置 | 为什么不能改 |
| --- | --- | --- |
| `https://meta.prismlauncher.org/v1/` | `Launcher_META_URL` | 版本清单 / 素材 / 库的唯一来源。Atlas 没有自建元数据服务，改了就没有版本可装 |
| `org.prismlauncher.EntryPoint` | `LauncherPartLaunch.cpp:129` | 游戏 jar 里的 Java 主类名，改了启动不了 |
| `x-prismlauncher-*` | `modplatform/packwiz/Packwiz.cpp` | packwiz 的 TOML 字段名，是包格式规范的一部分 |
| `cmake/vcpkg`、`libraries/libnbtplusplus` 子模块 | `.gitmodules` | 构建依赖与 NBT 解析 |
| `files.prismlauncher.org/fmllibs/` | `Launcher_LEGACY_FMLLIBS_BASE_URL` | 只服务 ≤1.5.2 的旧 Forge，正常地图不会碰 |
