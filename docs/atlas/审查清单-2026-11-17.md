## 1. 项目概况

Atlas：仅 Windows 的 C++/Qt 6.8 Minecraft 启动器 fork（基于 PrismLauncher，GPL-3.0）。核心反转——从"选版本→主菜单→挑存档"变为"点地图卡片直接落进世界"。新代码只进新目录、对既有文件只做加法：44 cpp + 49 h（24,465 行）集中在 `launcher/maps/`，另改造 `net/{Request,FileSink,DownloadSource}` 与 `ResourcePaths`。三硬约束：不坏档（版本判定带置信度/证据，判不出即拒）、机制还原（跑原生版本）、空间与等待可控（共享资源池 + 每实例独立 gameDir）。相对上游保留版本/实例/下载/模组/UI 语义，新增三级判定、地图嗅探、导入编排、≤1.19.4 Java Agent 直连与安全退出、大厅/本地地图库；删除了启动器内地图机器翻译（§83）与双模式主窗口。

**模块结构（分层）**：识别层（`MapArchiveScanner` / `LevelDatReader` / `MapVersionDetector` / `DataVersionTable`）→ 数据层（`MapMeta` / `MapNotes` / `MapRepository`）→ 导入层（`MapImportTask` + 同文件内的 `MapReinstallTask`）→ 地图库/大厅层（`MapLibrary` / `HallAPI` / `BrowserFetch` / `HallCache`）→ 启动退出层（`MapLaunchPrep` / `AgentBootstrap` / `MapQuitWatcher` / `MapWindowFocus`）→ UI 层（各 Page / Card / Dialog + `MapTheme` / `MapStyle`）→ 横切下载栈（`Request` / `FileSink` / `DownloadSource` / `DownloadMonitor`）与资源库（`ResourceStore` / `ResourcePaths`）。依赖关系：maps 单向调用 Prism 既有基础设施，QtConcurrent 任务经 QueuedConnection 回 GUI 线程；与上游同步面集中在 `CMakeLists.txt` 与 `MainWindow`。

**进展**：M0 / M2 完成，M1 / M3 / M4 / M5 主体完成但近期界面改动未真机复看；31 套件 / 423 项（文档记录 2026-11-15 实测，本次未独立复现）。文档体系在 §88 刚重构，工作区存在 20 项未提交改动（重构与注释修正）。
