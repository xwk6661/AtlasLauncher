# 00 · 工程约定

> 这一份只回答「动手之前必须知道的规则」：文档怎么写、数字怎么记、代码放哪、命令怎么跑。
> 违反它不会立刻出错，代价是下一次对表要花一整天，或者一次改名让 20 处路径失效。
>
> 状态与进度不写在这里（去 [04](04-进度与待办.md)），验证档位不写在这里（去 [05 §1](05-验证记录.md)）。

---

## 1. 文档体系

### 1.1 一份信息只有一个权威位

| 信息 | 唯一权威 | 其它位置只能 |
| --- | --- | --- |
| 状态、进度、**所有具体数字** | [04](04-进度与待办.md) | 引用，不复制 |
| 验证档位与证据 | [05](05-验证记录.md) | 引用 §，不复制证据 |
| 决策、理由、踩过的坑 | [03](03-决策与坑.md) | 引用 §，不改写理由 |
| 分层、数据结构、流程、模块职责 | [01](01-设计.md) | 引用 §，不重画 |
| 构建 / 测试 / 打包 / 数据迁移 | [02](02-构建与运行.md) | 给一条命令 + 链接 |
| 发布就绪与否、阻断项 | [07](07-发布清单.md) | 引用，不自己数 |
| 改过什么、为什么 | [06](06-变更记录.md) | 只增不改 |

对外文档（仓库根 `README` / `BUILDING` / `CONTRIBUTING`）是**摘要 + 链接**，不承担维护数字的义务。

### 1.2 编号即接口

- `06 §N` 被**代码注释**引用（40+ 处，`launcher/net/Request.cpp` 就有 14 处）。所以 06 **只追加、不重编号**；
- `01 §7.x`、`03 §5.x`、`04 P1 #7`、`05 §3 #31` 被文档互引。重组时**保留编号**，废弃的小节留"指针桩"
  （`§3 路线选择 → 已并入 03 §5.1`），而不是删掉让链接 404；
- 新增内容进现有小节的子标题，或进本文件，**不新开编号**。

### 1.3 每次改完跑一次校验

```bash
python tools/docs_check.py        # 链接 / 跨文档 § 引用 / 表格列数 / 06 重号
```

**0 问题才算改完**（`06` 的 §94/§95 是已知重号，脚本单列为"已知例外"）。

### 1.4 历史不改

`06` 的历史正文、`05` 里带日期的验证证据、`docs/atlas/archive/` 的审查留档，都不追改。
发现旧记录与现状不符时，**新增一条**说明差异，而不是回去改旧数字。

## 2. 数字与口径

写数字前先问三个问题：**谁测的、什么时候、什么单位**。三者缺一，下一个人就会拿它当现状。

| 项 | 口径 |
| --- | --- |
| 体积 | 一律 **MiB / GiB（1024 进制）**；给字节数时同时给 MiB。历史条目保留当年的 MB 写法，不换算 |
| 测试项数 | `passed + skipped`（例如 448 = 438 + 10）；**"全绿"= 0 failed**，不等于 448 项都真的跑了 |
| 测试耗时 | 只写实测区间（如 20.55–32.01 s），不写"约 20 秒" |
| 实例 | 数据根 `instances/` 下的目录数；其中带 `map.json` 的才是地图实例 |
| 地图库 | 索引条目数（包）→ 分组后的图数 → 大厅关联数（其中 `verified:true` 单独给） |
| 代码规模 | `cat launcher/maps/*.{cpp,h} \| wc -l`，别用编辑器行数 |
| 改动面 | 必须带基线提交（`git diff --shortstat <sha> HEAD`），否则过一天就变 |

数字只写在 04。README、07、02 里出现数字时，要么带日期标注为历史，要么改成链接。

## 3. 代码与提交

### 3.1 放在哪

| 改什么 | 放哪 |
| --- | --- |
| 地图相关新功能 | `launcher/maps/`（新文件优先） |
| 资源目录 | `launcher/ResourcePaths` |
| 下载栈 | `launcher/net/{Request,FileSink,DownloadSource}` |
| 既有上游文件 | **只做加法**：不改已有签名；新 getter 用新名字 + 默认参数 |

理由见 [01 §13](01-设计.md)：上游修复还要能 `cherry-pick` 进来，改签名等于每次都要打一次架。

### 3.2 提交

- 前缀：`feat(scope):` / `fix(scope):` / `docs:` / `docs(04):` / `chore:` / `refactor:`；
- 一个提交只做一件事；文档改动与代码改动分开提交；
- 不提交 `build/`、`dist/`、`*.zip`、`*.exe`。例外：`launcher/resources/agents/*.jar` 是**提交进仓库的产物**。

### 3.3 分支与版本

- `main` = 发布线，禁止强推与删除（仓库规则集强制）；工作分支 `feature/<主题>` 从 `main` 切出；
- 本地 `develop` 只是上游历史快照，不推送、不合并；
- 版本号在 `CMakeLists.txt`（`Launcher_VERSION_NAME`），tag 用 `v` 前缀（`v0.1.0`）；
- **`BuildConfig.cpp` 是配置期生成的**：打完 tag 必须重新 configure，只 `--build` 会沿用上一次的版本串。

### 3.4 格式化与静态检查

配置在仓库根：`.clang-format`、`.clang-tidy`、`.editorconfig`、`.markdownlint.yaml`。
**没有接入 CI**（见 §7 待确认），提交前自己跑。

## 4. 界面与本地化

- 新增界面的源串是**中文**（上游源串是英文，两套并存）；
- 改了 `tr()` / `uiText()` 的源串，必须同步 `launcher/resources/i18n/atlas_en.json`：

```bash
python tools/i18n_extract.py --check     # 缺一条 exit 1
```

- **只翻显示层**：会落盘的文本（`map.json` 的证据、`variant.label`）保持中文，否则同一份数据会随界面语言变化；
- 颜色走 `MapTheme.h`，尺度走 `MapStyle.h`，不要写死色值。

## 5. 命令行与环境变量

### 5.1 参数（`Application` 的 `QCommandLineParser`）

| 参数 | 作用 |
| --- | --- |
| `-d, --dir <目录>` | 指定数据根（`.` = 当前目录）；便携根与 Debug 沙箱都靠它 |
| `-l, --launch <实例 id>` | 启动指定实例（id = 实例目录名） |
| `-s, --server <地址>` | 启动后直连服务器（只能配 `--launch`） |
| `-w, --world <世界>` | 启动后直连存档（只能配 `--launch`） |
| `-a, --profile <名字>` | 指定账号（只能配 `--launch`） |
| `-o, --offline <玩家名>` | 离线启动（只能配 `--launch`） |
| `--show <实例 id>` | 只打开实例窗口，不启动游戏 |
| `--show-window` | 启动时显示主窗口（常与 `--launch` 连用） |
| `-I, --import <路径/URL>` | 导入实例或资源；位置参数等价 |
| `--alive` | 启动后写一个存活标记文件（脚本探活用） |

### 5.2 环境变量

| 变量 | 谁读 | 用途 |
| --- | --- | --- |
| `PRISM_NET_IDLE_TIMEOUT_MS` | `Request` | 空闲看门狗窗口（默认 20000）；单测压到几百毫秒 |
| `PRISM_DOWNLOAD_CHUNKS` | `Request::parallelChunks()` | 没有 `Application` 上下文时打开分段下载 |
| `PRISM_MAP_FIXTURES` | `MapArchiveScan_test` | 指向 AIO 的 `launcher/fixtures`；没有就跳过门控用例 |
| `ATLAS_DATA_DIR` | `build/run-atlas-debug.cmd`（**脚本级**，不是程序读的） | 改 Debug 版的数据根 |

## 6. 路径与数据根

| 路径 | 事实 |
| --- | --- |
| `E:/Program File/AtlasLaucher` | **真实便携根，`Laucher` 就是少一个 `n`**。脚本与文档都按这个拼；"修正"它等于让所有路径失效 |
| `<便携根>/atlas.exe` | 真机一律跑这个，不跑 `build/win-local/Debug` |
| `%APPDATA%\Atlas\Atlas\agents\` | Agent jar 与 `introskip-*.log` 的唯一位置，**不在便携根**（`QStandardPaths::AppDataLocation`） |
| `D:\Games\PrismLauncher` | 本机共享资源库（`SharedResourceDir`）；`meta/`、`metacache` 不跟着走 |
| `build/win-local/Debug/` | 只有可执行文件、`portable.txt`、`translations/`；**不放任何游戏数据** |
